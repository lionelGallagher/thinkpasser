# 明亮商城与商品优先

> 历史探索记录。用户已否定终端功能、仿系统和后台表格式首页。最终视觉以 [亮色悬浮商城](2026-10-23-optical-storefront.md) 为准；本文不代表当前产品方向。

用户纠正：整页深色影响商品辨识，“FOR DEVELOPERS / 开发工作流”误导为仅服务编程；终端比例过大、文字小、装饰和重复信息过多。要求亮色系并从整体信息结构调整。

首页顺序改为：清晰导航 → 简短商城标题与紧凑查询窗口 → 跨场景商品及价格 → 工具入口与购买说明。桌面首屏应出现可比较的完整商品卡，手机端优先商品，查询辅助入口靠后呈现。

统一白底、冷灰页面、深色正文、清晰细边框与蓝色操作色；品牌色用于小型标识。查询窗口沿用现有命令能力，以白色窗口、紧凑命令输入和中文规格输出展示，移除虚构终端主机、路径、重复标签与旋转背板。轻微阴影和悬停反馈体现层次。

商店覆盖写作、研究、编程、图像与办公。程序员熟悉的查询方式是辅助入口，不限定商品用途。价格、商品范围、收藏、筛选、购物车与订单规则不变。验证桌面首屏商品可见性、移动布局、查询、分类和购买路径，并同步 README 与定位文档。
