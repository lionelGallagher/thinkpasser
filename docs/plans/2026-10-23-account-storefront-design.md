# 自营 AI 账号商城设计

## 已确认的业务

用户销售 AI 账号，自营定价和交付，不做多卖家市场。此前 README 的“不销售账号、模型选型与顾问预约”定位有误，应同时修正代码与文档。沿用“模型平权”名称，以 GamsGo 商品市场的信息组织为参考，完成更完整的商城前台。

## 页面与体验

- 商城首页：全局搜索、品牌分类、主推商品、热门账号、购物说明。
- 商品列表与 Claude 专区：品牌、独享/共享/代充、价格、交付方式筛选和价格排序；手机端筛选抽屉。
- 商品详情：套餐与期限、数量、具体交付内容、使用说明、购物车及立即购买。
- 购物车、确认订单、订单详情、我的订单：本地保存商品与待支付订单，支持取消订单。不模拟支付成功或账号已交付。
- 帮助中心与商店说明：面向商品购买、售后和订单查询，移除顾问选型与推广佣金文案。

## 视觉

清晰的电商信息密度；浅灰页面、白色商品卡、电蓝主色、暖色 Claude 商品视觉。缩短营销首屏，使真实商品内容尽早出现。使用本地 SVG 图形、产品品牌标识、细边框和统一排版；不依赖图片 CDN 或大型框架。

## 技术与数据

保留静态部署能力，拆分为 index.html、assets/styles.css、assets/store.js、assets/app.js。原有 hash 路由迁移到商城路由，旧模型目录和单品路径保留兼容跳转。金额使用整数分；购物车按商品与期限区分；订单创建时重新核验价格和库存；localStorage 存储异常可恢复并提示。配置为示例商品和示例库存，页面明确标注预览价格。真实库存、登录、支付、通知和凭证交付后续接后端。

## 验证

使用 Node 内置测试验证组合筛选、排序、金额、期限、库存上限、订单状态和输入校验。静态服务检查资源与所有路由；浏览器检查首页、筛选、详情、购物车与订单流程以及手机宽度。无后端时不声称具有真实收款和自动发货能力。
