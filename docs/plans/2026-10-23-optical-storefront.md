# 亮色悬浮商城

用户反复纠正：技术感指视觉意境，不是终端功能、仿 Linux 或后台表格；保持亮色、清楚展示商品，面向写作、研究、编程、图像和办公。

首页采用冷白背景、电蓝操作色、深色文字。三款首屏套餐以透明材质、立体悬浮的品牌图形建立空间层次，品牌、套餐、账号方式、价格和购买入口同时可见。八个品牌入口与场景分类连接完整目录，移除广告式大口号和统计概览。几何与材质以本地 CSS / SVG 绘制，不增加图片服务或运行依赖。

完整目录沿用首页同款商品卡、导航、配色和页面宽度，保留工具与套餐筛选、排序和分页。用户明确拒绝表格和侧边规格预览，全部移除。目录提供位置提示和返回商店入口；点击商品进入详情选择周期与数量。组织定制不能零元购买。页头、详情、交易和目录使用相同的明亮基调与操作色。

不提供终端、命令输入或系统操作。交互只使用轻微浮起和材质角度变化，支持减少动态效果设置。手机首屏商品可横向滚动，保留搜索和完整目录入口；后续商品采用双列布局。

保留现有纯前端订单、报价、库存与随机交付规则。资源版本由内容摘要生成，换行规范化后在 Windows 和服务器检出环境保持一致。
