# 开发者终端界面

用户明确目标为程序员，希望获得熟悉的命令行窗口、深色技术配色和悬浮感，拒绝灰绿配色与首页目录统计面板。

采用深色石墨底、冷蓝高亮、窗口标题栏与等宽输出；终端背板、柔和投影和缓慢浮动体现层次，卡片悬停轻微抬升。减少动态效果时停用位移动画，输入聚焦时暂停终端浮动。目录、详情、购物车、订单、表单与弹窗统一深色主题。

首页终端读取实际商品数据，支持 `show <brand> [--plan <tier>] [--mode <mode>]`、`list [brand]`、`search <query>` 和 `help`，可选 `tp` 前缀。命令通过白名单解析，不执行 Shell 或任意 JavaScript，不写交易数据。输出转义用户输入，结果链接进入现有商品页。

验证：新增解析、组合查询和无效输入测试，先验证失败再实现；浏览器检查快捷查询、Enter 提交、帮助、无匹配结果、商品详情跳转、深色购买流程及手机宽度。保留现有价格、库存配置与订单兼容规则。
