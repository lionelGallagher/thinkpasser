## 退款、补时、续费与换机的统一规则

本节按最新原则校正执行范围：**电脑可以独立购买，平台AI必须关联电脑；Claude与Codex彼此可选。** 电脑是交付与访问控制的基础，AI是其可选权益项。

| 场景 | 收费、退款或补时 | 处理后的服务状态 |
| --- | --- | --- |
| 只买电脑 | 只收电脑费用；电脑故障按既定资格补时，不计算任何AI退费。 | 电脑继续按自身租约使用。 |
| 给电脑加购AI | 只收本次选择的Claude／Codex费用，沿用全额30天标准价与实际期限披露。 | 关联目标电脑租约；正常准备等待补电脑时间，AI原截止不延。 |
| 正常主动不再使用 | 不退电脑或AI剩余费用，不生成余额或抵扣。 | 保留原已购服务到各自截止，不因表示不用就提前清机。 |
| 客户主动换机／升级 | 新电脑按全价新购；新单所选AI才重新购买，也可以只买新电脑。旧电脑、旧AI均不退不抵，不按差价升级。 | 客户自行导出并确认后结束旧租约、清旧机；旧平台AI不自动带到新单。 |
| 故障提供替代机 | 不按主动换购新增一套收费。 | 继续原租约及已购权益，修复／迁移只覆盖实际可恢复内容。 |

| 电脑故障但继续服务 | 按已定申报资格补电脑时间；仅对确已购买且仍处承诺期的AI退受影响部分，去重且不超原实付。 | 电脑和其余有效AI继续；部分故障现金赔付不等于取消AI服务，AI不自动延期。 |

| 电脑到期 | 正常到期不算故障，不退正常已开通费用。 | 拒绝新远控并断开已有远控；AI上游可能仍有效，但本平台不提供脱离电脑的接入；保留3天受限导出后按规则清理。 |

### 本次校正的关键边界

- 退款必须关联原电脑交付单元或租约；涉及AI时还要关联原AI订单项，涉及故障赔付要关联客户工单。多台订单只处理受影响的一套。
- 电脑服务结束或已整套退款，关联AI同步结束平台交付；只取消或终止某项AI时，有效电脑继续。这里说的是平台交付状态，不等于官方订阅已被取消。
- 纯电脑不自动收费AI、补偿AI或续上AI。主动换机可以选择新纯电脑，不强制购买原来用过的AI。
- 一段故障的现金赔付与“退剩余费用并结束该项服务”分别记录。前者继续履约，后者结束对应项，不能用一个“已退款”状态混在一起。
- 客户已付款订单保留金额和商品快照。上游成本变化不自动要求客户补款；客户主动新增商品或换购，再明确确认新订单金额。
- AI故障退费是平台向客户支付的售后费用，上游长期开通成本不预设可退；供应商承担损失须有真实合作约定。

**保留原已确认的故障保障。** “AI故障后只退该AI、电脑仍可用”符合“有电脑不一定有AI”，不需要删掉；需要禁止的是退款后仍把AI作为脱离电脑的独立服务交付。

## 两类供应商与平台的分工

按用户最新澄清，平台围绕**电脑供应商**与**卡／订阅供应商（用户所说的卡供应商）**两类供货角色组织。AI开通是卡／订阅侧的供货任务，不另设固定第三类“AI开通供应商”。自营和外部合作方均使用供应商端，一家机构也可同时承担两类角色。

| 参与方 | 职责 |
| --- | --- |
| 电脑供应商 | 提供Windows／Mac电脑、初始环境及机器侧运维，提交资源供平台验收。 |

原先已确认供应方给指定邮箱／账号开通订阅，仍按这条规则执行。开通任务可由合作方或平台自营的卡／订阅供货身份承担，按实际交付能力分派，不因“卡供应商”名称就假定所有发卡方都能办理AI开通。

卡资源、付款成功、目标AI账号、订阅可用和电脑租约是不同记录：有卡或付款成功不代表Claude／Codex已经可用，仍需核实开通结果并与该台电脑整套验收。客户只能买电脑或电脑搭配AI，不能脱离电脑单卖平台AI权益。

## 供应商入驻与客户收款

### 供应商入驻

供应商支持两种入口：平台管理端创建供应商账号，或供应商自己注册申请。两条路径都要经过审核才取得供货权限。账号审核与具体机器、AI开通能力、卡资源的验收分别记录，不能把通过入驻审核当作所有资源已可交付。

自营和外部合作方采用同一供应商流程，按电脑与卡／订阅两类角色供货；指定账号开通是卡／订阅侧的供货任务，不另加固定第三类供方。供应商供机数量不受客户账号“一账号同时一台独享电脑”的使用分配限制。

### 客户收款

网页及Windows／Mac客户端计划支持支付宝、微信支付、国际银行卡及PayPal，共用商品、订单、收款和退款服务。只有客户主账号可购买、续费和加购，子账号继续只使用已分配资源。

每笔付款记录实际渠道、币种、金额和交易号；退款关联原订单和原付款渠道。供应商费用、卡资金及支付给客户的退款分别记账，不把上游充值当作客户付款成功，也不把客户退款当作上游卡余额已返还。

以上为已确定的产品能力。实际渠道开通、接口配置和支付结果验证仍需接入，尚未接通的渠道不显示为已可支付。

### 电脑为基础，Claude 与 Codex 为可选权益

用户最终明确：有平台提供的Claude Code或Codex权益，必须有对应的平台电脑；有电脑不一定购买这两项权益。Claude和Codex可各自选择，也可同时购买，不要求先买Claude才能买Codex。

| 购买组合 | 是否支持 |
| --- | --- |
| 只买电脑 | 支持 |
| 电脑＋Claude Code | 支持 |
| 电脑＋Codex | 支持 |
| 电脑＋Claude Code＋Codex | 支持 |
| 没有电脑，只买Claude Code或Codex权益 | 不支持 |

首单可以同时购买电脑和AI；也可以给已有电脑加购AI。AI订单项必须关联同单电脑交付单元或现有可加购租约，不能形成脱离电脑的AI订单。电脑与卡／订阅两类资源由平台组合交付，不要求一家供方同时供两类。

电脑的连接资格按租约、到期时间和账号分配校验；AI自身状态与有效期独立记录。AI到期不锁住有效电脑，电脑到期则按既定规则停止完整远控。

### 平台控制权限以电脑租期为准

用户确认平台的完整桌面访问以电脑租期为主。电脑可以单独购买；连接时验证账号状态、当前身份的机器分配、交付及租约状态和电脑到期时间，不把是否买AI或AI是否到期作为整机连接条件。

| 状态 | 平台应有行为 |
| --- | --- |
| 电脑有效，未买AI | 可进入完整电脑，使用已配置的软件；不凭空授予未购买的AI权益。 |
| 电脑有效，已买AI | 可进入电脑；AI能否使用依据所购权益及上游真实状态。 |
| 电脑有效，AI已到期 | 仍可进入电脑，AI另按续费处理。 |
| 电脑到期 | 拒绝新远控并主动断开已有远控；不能靠一直保持连接继续使用。 |
| 到期后3天保留期 | 可登录平台、续费、看订单、提工单，并从独立受限入口导出文件；不开放完整桌面。 |
| 保留期结束 | 按既定规则清理客户数据及凭据，恢复最新初始环境、验收后重新入库。 |

电脑补时不自动延长AI；平台承诺截止与上游真实订阅截止继续分别记录。到期控制覆盖网页和客户端的同一授权服务，不能只在客户端隐藏按钮。

这条规则控制本平台的电脑入口。客户若持有自己的AI账号或登录凭据，电脑租期本身不能阻止其在平台外登录该账号，也不能保证收回第三方订阅。

AI故障退款／赔付与访问控制分别处理：符合既定售后条件时，由平台从原收款订单向原付款人支付；上游长期供货成本不因这笔支付自动退回。供应方是否承担损失依据合作约定核实，不预设能单方扣其结算款。上述仍为待接入的执行设计，不表示已开通官方退款或真实支付接口。

### R02 已确认：主动换机按新订单购买

| 项目 | 最终规则 |
| --- | --- |
| 旧电脑费用 | 剩余费用不退、不抵扣。 |
| 新电脑费用与租期 | 按新订单全价购买，验收开放时开始新周期。 |
| 旧 AI 与新 AI | 新单可只买电脑；选择哪些AI才新购哪些AI，不强制重买旧AI。旧AI剩余费用不退、不抵，也不带到新单。 |
| 旧机资料 | 客户先自行导出，主账号确认后再清空旧机；不由平台迁移环境。 |
