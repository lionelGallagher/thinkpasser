# 前端交接与本地验收

## 本地入口

根目录 `npm install`、`npm run dev`，端口5180：

| 入口 | 地址 | 覆盖 |
| --- | --- | --- |
| 客户网页 | /web/ | 工作空间、选购、订单、电脑、团队、工单、登录 |
| 平台管理 | /admin/ | 资源、账号、供方、任务、商品、交付、售后、成本 |
| 供应商 | /supplier/ | 当前供方资源、任务、回报、成本和资料 |
| 桌面界面 | /client/preview/ | 保存账号、我的电脑、工作区和偏好 |

四个入口共用Vue／TypeScript组件和本地演示状态，同一浏览器不同入口通过storage事件同步演示更改。桌面入口是界面预览，不是原生安装包。没有手机App。

## 一条可复核的演示链路

1. 客户网页选电脑，搭配零个、一个或两个AI，明确邮箱来源和费用后创建演示订单。
2. 我的订单选择演示付款方式并确认模拟结果；订单进入准备，初次电脑仍未起租。
3. 供应商端切换对应供方，接电脑／AI任务并回报准备说明；订阅任务只向负责供方显示目标邮箱。
4. 管理端逐项演示验收；少一项时单元仍不能交付。全部通过后在订单页开放交付。
5. 客户网页团队资源出现该单元，主账号分配给空闲账号；账号已有电脑或交接预留时拒绝第二台；交接验收前保持不可进入，管理端可完成明确标识的演示验收。
6. 被分配账号登录后进入桌面预览；新子账号需要先完成演示改密。主账号管理他人电脑时不能进入其桌面。
7. AI加购仍全额收费，承诺截止冻结原电脑日期；等待只从演示付款确认开始补电脑时间，AI不顺延。

演示不读取真实桌面或文件，不执行命令，不发邮件，不产生收退款或订阅。上架／停供和商品编辑仅修改本地演示，真实供应状态仍需后端验证。

## 数据和界面边界

- localStorage仅用于演示状态／目录，版本化并可恢复初始数据；非生产身份或持久化方案。
- 演示账号切换重新计算可见资源，并退出原桌面预览；没有合并权限。
- 初始密码仅作输入校验，不存进演示状态；机器连接密码不以明文出现在界面。
- 保存商品时，旧订单保留产品配置和成交金额快照；真实模式也必须保持这一点。
- 未接入动作明确提示，真实服务失败时不能自动回退成演示成功。
- 桌面中的编辑器和终端是本地交互示例；媒体、中文输入协议、文件和系统声音另行真机验收。

## 验证命令

```powershell
npm run typecheck
npm run test:ui
npm run build
npm test
npm run verify:design
```

完整契约格式和正反字段案例：

```powershell
python -m pip install -r backend/contracts/requirements.txt
python backend/contracts/validate_design.py --full
```

前端测试使用Vitest＋Vue实际挂载＋happy-dom，由小型DOM驱动触发界面事件，不替代真实浏览器渲染、键盘焦点和截图。浏览器截图启动曾被自动审批拒绝（blocked by policy）；当前环境也没有Computer Use所需的node_repl，因此未绕过该限制。

后续验收按[难点清单](06-difficulties-and-validation.md)补充真实浏览器、原生主机、MySQL竞争、Java API及支付供货结果。当前不把“前端交互通过”写成生产端到端完成。

## 产品界面与本轮闭环

页面以当前工作为中心：客户首先看到自己的电脑和连接入口；商品页只保留配置、价格和选择；管理端／供方优先显示待处理任务。移除欢迎广告、立体硬件装饰、能力宣传和侧栏推广。中性表面、深色主操作、足够留白，颜色只辅助状态；产品风格不等于套用某品牌配色。

供应商示例增加纯卡经销商与自营开通执行方，仍为两类供方体系。纯卡资源不填写 AI provider，也不向纯卡任务展示客户邮箱。资源验收与指定账号 AI 验收分开。localStorage 演示格式升为 v3，旧演示状态不迁移，重新加载初始样例；这不是生产数据迁移策略。

修正跨到期时仍显示桌面的响应式时钟、换人先验收再开放、同 provider 多次续费精确交付、重叠等待只补一次电脑。真实后端按[生产矩阵](09-end-to-end-matrix.md)另做事务与设备验证。

## 个人、团队与最新复核

默认个人示例，用户菜单可开通团队并保留订单／电脑／AI；“切换演示”中的个人／团队会恢复对应示例数据。个人首单交付自动给本人；已有有效电脑时新机显示待切换，客户先导出旧文件再确认，旧剩余不退不抵。团队桌面客户端与网页均可在团队资源页分配机器。

已复现的旧报价、迟到验收、旧确认、导出归属及原AI账号续订等问题见[复核记录](11-review-and-personal-workspace.md)。本地演示格式为v3，旧演示状态不迁移；生产数据不得采用这种重置方式。
