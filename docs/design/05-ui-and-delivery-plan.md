# 四端页面与开发任务

## 页面行为

| 入口／页面 | 显示内容与核心动作 | 权限／异常 |
| --- | --- | --- |
| 网页：商品 | Windows／Mac、地区、CPU／内存／硬盘、电脑周期、可选Claude/Codex；筛选及组合报价 | 缺货不能付款；金额以服务端quote为准 |
| 网页：下单 | 目标AI邮箱来源、预计准备、费用和实际期限、准备期取消条款 | main可买；按quote哈希确认；付款成功由服务端核验 |
| 网页：电脑 | 我的已分配电脑；main另有团队待分配资源；电脑与各AI截止分别显示 | 子账号仅自己；main管理权不等于进入所有桌面 |
| 网页：订单 | 每单元准备、AI开通、验收、开放及退款状态 | 多台部分交付分别计时；真实状态未知不显示成功 |
| 网页：团队 | 直接建子账号、初始密码重置、停用、分配、收回 | 唯一有效分配；收回选择保留文件或重置，凭据独立处理 |
| 网页：工单 | 选择自己的电脑／AI、描述、证据、处理进度及方案确认 | 子账号不操作资金；给明确修复窗口，不承诺即时赔付 |
| 桌面客户端 | 保存多个登录账号、切换、我的电脑、一键连接、接管确认、文件／声音／显示、购买回跳 | 仅Windows／Mac，无手机App；普通界面不开放任意ID连接 |
| 管理端：资源 | 机器配置、供方、可售／在租／保留／重置／隔离、健康分项 | 受限恢复、实际证据、unknown处理；不自动获取客户桌面 |
| 管理端：商品 | 规格、售价、AI选项、库存规则、准备时限、上下架 | 变更只作用新quote，不改已成交订单快照 |
| 管理端：供方／任务 | 申请审核、两类能力、派单、回报、验收及成本 | report≠verified；取消后迟到回报仍对账 |
| 管理端：租约与售后 | 账户与分配、交付、到期、保留、补时、AI故障、退款 | 系统算金额，人工核定事实，原渠道执行 |
| 供应商端：入驻／资源 | 申请、审核状态、自己资源和报价、交付能力 | 未审核不供货；可同时具备两类角色 |
| 供应商端：任务／结算 | 接单、指定邮箱／资源、准备、回报、失败、成本和付款记录 | 只看自己任务，不看到客户所有财务和登录秘密 |

账号登录方式、正常列表、搜索、表单校验、分页和设置按字段契约实现。重要金额、期限、文件清理和控制中断需清楚确认，不能用“安全原因”掩盖实际收费／服务时长。

## UI 状态统一

每页至少处理loading、empty、ready、error；异步操作另有pending／unknown，不以toast代替持久结果。网络错误保留已填表单。重复点击复用幂等键；修改参数生成新键。账号切换清空当前账号的数据缓存和正在请求的响应，旧响应不得覆盖新身份页面。

机器操作按钮由服务端资格产生；前端仍按角色隐藏不适用动作。desktop、export_only、none与AI状态分别渲染。到期不隐藏续费和工单；三天保留只出现允许的导出动作。

前端演示模式有常驻标识，可产生本地演示订单／状态；真实模式由环境配置，未接后端不得演成真实付款、开通或机器重启。演示种子使用虚构邮箱／设备，无真实凭据。

## 实现归属与依赖

| 任务 | 目录与负责人职责 | 输入 | 完成条件 |
| --- | --- | --- | --- |
| F01 网页商品及客户台 | web | quote、order、machine、team、ticket DTO | 四组合、角色、到期及交付状态交互可验证 |
| F02 内部管理台 | admin | resource、supplier、task、operation、ticket DTO | 审核、派单、回报验收、故障事实核定闭环 |
| F03 供应商门户 | supplier | 自身资源、任务、ledger | 电脑／订阅两类接单与回报，不越权 |
| F04 桌面界面 | client | 同一业务API、RemoteHostAdapter契约 | 登录切换、自己电脑、接管及购买回跳；真实原生集成单验 |
| B01 身份、租约及数据层 | backend Java | 数据设计、T01—T06、OpenAPI | MySQL迁移与唯一约束、权限和竞争测试 |
| B02 供货资金售后 | backend Java | T04/T10/T11/T12/T14/T15/T16 | 原收款、供方回报和验收可对账，异常不重复履约 |
| R01 原生授权与凭据 | client/rustdesk | T07/T08/T13、密码生命周期 | 真机改密、到期、重连和接管无旁路 |
| R02 网页远控 | web/remote-desktop | R01身份、编码帧与通道绑定 | Windows/Mac真机，中文／文件／声音／跨网验证 |
| D01 回收与恢复 | backend＋client | T06/T08/T09、供方能力 | 无误清理、只导出、真实恢复及回库证据 |

常规业务可先按契约写前端；R01/R02必须及早验证技术路径。所有demo、stub、not_configured明确标注，不能以界面完成替代真机和商业接口验收。

## 生产闭环补充

客户端主账号具有选购、订单和团队入口；子账号在网页及客户端均禁止购买页。供应商资源与任务按纯供卡、开通能力区分，不新增客户卡商城。采购、上游事实、结算及单元决策字段由新版 OpenAPI 的 T14—T16 约束，完整场景和上线证据见[端到端矩阵](09-end-to-end-matrix.md)。演示状态不代替真实资金和设备结果。
