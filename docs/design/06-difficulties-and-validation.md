# 项目难点与验证计划

这是工程风险和验收计划，不是已完成真机验证的报告。普通页面、登录表单和列表不是主要技术风险；必须分别拿到业务约束、协议和外部实际效果的证据。

## 难点清单

| 编号／难度 | 问题与设计 | 验证场景和通过标准 | 失败处理 |
| --- | --- | --- | --- |
| H01 高 | 网页接入真实RustDesk主机；优先验证被控侧编码帧适配，Java只负责业务控制 | Windows/Mac各一台；真实画面、中文、输入、文件、声音；直连与强制中继；浏览器不支持时明确拒绝 | 技术探针失败后调整协议／编码路线，不将合成回环当可交付 |
| H02 高 | ID＋永久密码可能绕过租期；平台grant与底层认证双检查 | 原生／网页、直连／中继／重连／文件；到期已有会话也关闭；旧凭据和grant均不能进入下一租约 | 阻止交付，补齐被控端守卫；OS管理员场景要验证供方外部控制 |
| H03 高 | 换人、续费、导出、清理同时发生 | 两个数据库连接竞争：续费先提交则旧清理不执行；清理先claim则不承诺原环境恢复；不同租户不可看残留文件／token | 状态unknown／quarantined，禁止回库，人工核验 |
| H04 高 | 卡、付款、认证、登录、实际AI调用分别完成；两个供方组合履约 | 对指定邮箱核验；初次所购AI全部就绪才起租；加购中电脑可用；取消后的迟到开通不误交付 | 客户按已定未交付异常选项处理，成本另记 |
| H05 高 | 跨系统支付／退款结果未知和重复 | 回调重复、乱序、超时、金额币种不符、退款重试；最多一次业务入账，不超过实付 | 保留预留和unknown，查询对账；无真实渠道不显示已收／已退 |
| H06 中高 | Mac长期运行后失联，进程和心跳可能正常 | 至少48小时技术探针，再做7天持续运行；休眠／断网／远控进程故障；分别观测Agent、服务和桌面 | 受限手动恢复，分层核验；没有日志不能先定成端口占用 |
| H07 中高 | 主子账号、管理权和桌面权分离 | main买多台但仅实际分配给自己的一台可控制；sub不能购买／重装／看他人；快速账号切换不串数据 | 服务端拒绝，撤销受影响会话，保留审计 |
| H08 中高 | AI退款分母固定、补时不延AI、多工单重叠 | 300元／20天故障1天=15元；相交工单只计区间并集；纯电脑0AI；补时后原AI截止不变 | 计算错误阻止执行资金动作，人工核定事实，系统重算 |
| H09 中高 | 跨国网络、编解码、中文与系统权限 | 两OS双向、至少两浏览器；中文组合只发送一次；快捷键；UAC与Mac屏幕／辅助功能权限；丢包、抖动和重连 | 显示能力和网络错误，恢复不越权、不无限积帧 |
| H10 中 | 裁剪、打包与自家更新维持约束 | UI／CLI／URI／消息路径不能恢复摄像头等排除能力；Windows签名、Mac签名公证及更新后复验 | 停止发布，保留固定源码和许可；不回退原厂未裁剪更新 |

## 设计验证与真实验收分开

| 层级 | 当前可检查 | 不能据此证明 |
| --- | --- | --- |
| 需求一致性 | 原始13题、确认数据、电脑依赖AI规则、售后金额和权限交叉检查 | 未来供方或外部规则永远不变 |
| 契约一致性 | OpenAPI格式／引用／字段案例，状态转换、角色、事务编号与文档链接 | API已实现、MySQL迁移已执行 |
| 现有参考测试 | 租期、会话参考、协议和设备健康参考 | 已实现真实桌面、支付或重启 |
| 后续Java集成 | Maven构建、真实MySQL唯一约束、事务／双连接竞争、HTTP权限 | 外部副作用实际完成 |
| 真机／渠道联调 | 原生与网页、供方开通、收退款、擦盘及恢复 | 其他未经测试的OS／浏览器／供方也支持 |

## 推荐测试数据

四种商品组合；main＋至少两个sub；两家电脑供方＋一家订阅供方，其中一个自营；一单三台不同交付进度；有效、到期瞬间、保留末尾、已开始重置四种租期；AI无购买、准备、有效、中断、到期；重复回调、旧版本任务和操作unknown。

性能探针先记录目标环境、码率、分辨率、帧率、端到端输入延迟、CPU／内存和中继流量，再定承诺。工程初值可用1080p／30fps作为测试档，不能对尚未测量的跨国网络承诺统一延迟。

## 可进入开发的条件

数据归属、角色、状态、金额和时间的规则已经给出；普通功能可依照接口与页面表实现。H01—H06仍需在专项实现中取得实测证据。发现做不到的原生接口或供方承诺时，先记录具体差距并调整技术路径，不能靠前端成功提示填补证据。
