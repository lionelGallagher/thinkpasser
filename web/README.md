# 网页端

客户使用的产品网站和控制台目录，包含商品浏览、下单、续费、登录及浏览器远控。

## 产品职责

- 销售纯电脑或电脑搭配 Claude Code、Codex 的组合；不独立销售平台 AI 权益。
- 主账号购买、续费、加购、创建子账号、分配电脑与提交售后；子账号只使用自己的资源。
- 展示准备、验收、交付、租期、AI 权益和工单的真实服务端状态。
- 浏览器连接获授权的 Windows／Mac；电脑到期后保留平台登录、续费及三天受限导出入口。
- 支付与身份服务由 [backend/](../backend/README.md) 提供，不在浏览器决定到账、库存或租约。

## 现有内容

[remote-desktop/](remote-desktop/README.md) 是保留的协议与浏览器合成验证工程，含本地静态服务、协议测试及会话授权参考模块。授权模块是测试参考，不是生产身份或网关服务。

```powershell
npm run test:web
npm run demo:web-remote
```

在仓库根目录运行，打开 <http://127.0.0.1:4187>。该页面不是产品网站，且未接入真实主机。商品页、客户控制台及真实浏览器远控仍待实现。
