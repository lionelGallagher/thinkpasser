# 网页端

默认个人空间直接购买和使用本人电脑，团队功能在开通后出现；账户菜单可开通团队且保留原订单／电脑／AI。个人和团队示例可在“切换演示”中查看。

客户产品网站和控制台。交互前端使用 Vue 3＋TypeScript；数据来自明确标识的本地演示适配器，尚未接入生产 Java API。

## 运行

在仓库根目录执行：

```powershell
npm install
npm run dev
```

打开 <http://127.0.0.1:5180/web/>。同一服务也提供[管理端](http://127.0.0.1:5180/admin/)、[供应商端](http://127.0.0.1:5180/supplier/)及[桌面界面预览](http://127.0.0.1:5180/client/preview/)。

## 页面与交互

- 工作空间、商品筛选、系统／地区／搜索、纯电脑及Claude/Codex自由组合。
- 结算表单、指定邮箱来源、实际AI截止披露、演示订单与四种付款方式选择。
- 电脑列表、主子账号切换、独享分配、保留期导出示例、AI加购和续费。
- 团队建子账号、首次改密状态、停用、收回与保留／重置选择。
- 订单分单元准备、供货任务、验收和交付；工单提交及处理状态。
- 邮箱密码／验证码登录界面及注册表单演示。

演示密码为 `demo-pass-123`，演示验证码为 `123456`；它们不用于真实认证。生成的初始密码不保存到演示状态。示例邮箱使用example.invalid。页面会明确标识未真实收款、开通订阅、连接或重启机器。

## 代码与接入

`app/` 为页面和表单，`shared/` 为通用组件、样式、类型、目录和演示状态，`test/` 为规则与DOM组件交互测试。演示价格／资源可重置，不代表实际商品或供应承诺。

生产身份、库存、金额、租期、远控权限和资金执行必须由[后端](../backend/README.md)确定。接入时依据[API契约](../backend/contracts/openapi.json)将演示动作替换为认证服务调用；不能将localStorage当生产数据库或权限边界。演示模型对传输层作了简化，不声称62个接口已实现。

```powershell
npm run test:ui
npm run build
```

构建输出到忽略目录 `.preview/dist/`，包含四个入口。真实浏览器截图、跨浏览器焦点与布局仍需补充验收；现有组件测试使用happy-dom。
