# 管理端

平台内部运营人员使用的管理后台，与客户主账号的团队管理界面分开。

## 职责

- 审核供应商，管理自营和合作方的电脑、卡／订阅侧资源与供货能力。
- 纳入及验收机器，维护商品、客户售价、库存、交付模板与上下架。
- 管理客户主子账号、租约、分配、订单和准备／交付任务。
- 查看真实健康状态，按权限发起机器恢复及回收。
- 核实客户工单，执行已确认的电脑补时、现金赔付与退款。
- 分别记录客户收款、供应成本、预付款／应付款和结算。
- 到期撤权、三天保留、清理重置与回库状态管理。

电脑供应商与卡／订阅供应商是两类角色；AI 开通属于卡／订阅侧任务。平台直接开卡、充值、冻结、销卡不是当前已确认的必需功能，相关操作由供方按自己的流程管理。

当前目录用于落实职责和后续产品代码，尚无管理端界面或生产 API。后端规则与参考链路见 [backend/](../backend/README.md)，需求见 [确认记录](../docs/questionnaires/远程电脑平台完整需求确认表.md)。
