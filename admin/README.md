# 管理端

平台内部运营前端，位于 `app/AdminDesk.vue`，复用网页端的订单、商品、工单和公共组件。根目录运行 `npm run dev` 后打开 <http://127.0.0.1:5180/admin/>。

已实现本地演示界面：运营总览、机器与资源、客户主子账号、订单交付、供应商审核、任务验收、商品配置／上下架状态编辑、售后工单及资金／供货成本展示。

供方回报先进入待验收，全部所购内容验收后才能演示交付；分批单元分别起租。商品修改只影响后续演示报价，已有订单保留配置与金额快照。

真实平台权限、供货证据、受限恢复、实际赔付、收退款和结算等待Java后端接入。运营身份不自动获得客户桌面或AI账号凭据，界面里的演示切换不是生产认证。
