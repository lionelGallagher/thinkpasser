# ThinkPasser

> 一张会员卡，用遍好用的 AI 助手。

ThinkPasser 是一个面向同学的 AI 会员订阅站：同学在网站上买月卡 / 季卡 / 年卡，登录即可使用编程、论文、英语、通用对话等 AI 助手，无需自己注册其他平台、无需接触 API Key。

后台由 ThinkPasser 统一接入国内大模型（DeepSeek / 通义千问 / Kimi 等），同学买到的是 **ThinkPasser 自己的会员服务**，不是第三方平台的账号。

## 当前状态

🚧 **前台原型阶段**：`index.html` 是纯静态单页应用，所有页面均可点击。登录、注册、支付、对话都是**前端模拟**（数据存在浏览器 localStorage），尚未接入后端，不产生真实扣款。

## 快速预览

无需安装任何依赖，直接用浏览器打开：

```bash
open index.html
```

## 页面结构

天蓝色主色调，布局参考订阅类平台，保持简洁。

| 路由 | 页面 |
|---|---|
| `#/` | 首页：横幅、热门会员、同学评价 |
| `#/products` | 全部会员，按分类筛选 |
| `#/p/<id>` | 会员详情：功能、流程、常见问题、套餐选择 |
| `#/checkout/<id>/<plan>` | 确认订单：支付方式、优惠券（演示码 `THINK10`、`STUDENT`） |
| `#/pay/<orderId>` | 扫码支付（演示二维码 + 15 分钟倒计时） |
| `#/success/<orderId>` | 购买成功：订单回执 + 撒花动画 |
| `#/login` `#/register` `#/forgot` | 登录 / 邀请码注册 / 找回密码（任意输入即可） |
| `#/account/{subs,orders,invite,settings}` | 用户中心：我的会员、订单、邀请好友、账号设置 |
| `#/chat/<id>` | 对话页（演示回复），未开通的助手会提示去开通 |
| `#/invite` `#/help` `#/doc/<terms,privacy,refund,contact>` | 邀请返利、帮助中心、协议与联系页 |

**演示购买流程**：会员详情 → 立即订阅 →（未登录先注册）→ 确认订单 → 提交订单 → 我已完成支付 → 购买成功 → 立即使用。
