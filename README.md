# 模型平权

> 先选对模型，再为它付费。

模型平权是一个面向华人用户的 **AI 模型选型与开通服务**：按任务、团队规模和工具链对比主流 AI 的能力边界，帮用户判断哪款值得付费，再由中文顾问协助在**官方渠道**以用户本人名义开通。

本站不销售、不转让任何第三方账号；收入来自推广佣金和企业服务。

## 当前状态

🚧 **前台原型**：`index.html` 是纯静态单页应用，所有页面可点击。预约记录暂存在浏览器 localStorage，**尚未接入线索后台**（见 `submitLead` 中的 TODO），正式推广前需要接上。

## 快速预览

```bash
open index.html
```

## 页面

| 路由 | 页面 |
|---|---|
| `#/` | 首页：终端风格首屏、免费 vs 付费对比、时间价值计算器、模型目录、开通流程 |
| `#/models` | 模型目录，按 通用 / 编程 / 检索 / 图像 / 办公 筛选 |
| `#/m/<id>` | 模型规格：模态、强项、局限、能力评分、付费版提升、版本选择 |
| `#/compare` | 能力对比矩阵，6 个维度，点击表头排序 |
| `#/advisor` | 三步选型工具，输出匹配度排名与建议版本 |
| `#/book/<id>/<plan>` | 预约开通表单（个人 / 企业） |
| `#/done/<id>` | 预约成功回执 |
| `#/mine` | 我的预约 |
| `#/business` `#/help` `#/doc/<about,privacy,disclaimer>` | 企业服务、帮助、关于 / 隐私 / 免责声明 |

## 收录产品

ChatGPT · Claude · Gemini · Cursor · Perplexity · Midjourney · Microsoft 365 Copilot · Notion AI

能力评分为编辑主观评估（1–5），价格不在站内展示，以各官网为准。产品标识使用首字母色块，未使用官方 logo。

## 合规要点

- 页脚与免责声明注明：**独立平台，与所提及品牌无隶属关系**；商标归各自所有者。
- 按 FTC 要求披露：**部分链接为推广链接，我们可能获得佣金**。
- 预约表单需用户勾选同意隐私政策后才能提交。
- 评价、开通人数等营销数据已全部移除。

## 部署

服务器上以 Docker 运行 nginx 托管静态文件：

```bash
scp index.html ubuntu@<server>:~/thinkpasser/site/index.html
# 容器：thinkpasser（nginx:1.27-alpine，80 端口，--restart unless-stopped）
```
