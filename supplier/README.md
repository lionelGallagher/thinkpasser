# 供应商端

供自营团队及外部合作方使用的统一供货门户。

## 两类供货角色

| 角色 | 内容 |
| --- | --- |
| 电脑供应商 | 登记 Windows／Mac、配置、初始环境、可交付状态和机器侧维护能力 |
| 卡／订阅供应商 | 登记卡／订阅侧资源与真实能力，承接指定账号开通、续订及供货售后 |

一家机构可具备两类角色。AI 开通是一类供货任务，不固定增加第三类供应商；卡已准备或付款成功不等于 AI 已开通。

## 流程

1. 平台创建供应商账号，或供应商自行注册申请。
2. 审核供货权限，并分别验收具体资源与能力。
3. 提交资源、报价、可接单量、预计交付时间及售后条件。
4. 接收平台任务，回报准备、开通、失败及实际交付结果。
5. 平台组合电脑和所购 AI，验收后向客户交付。
6. 跟踪供货售后及结算；退出前处理在租服务。

卡资源自身的开卡、充值、冻结和销卡由供方管理。平台记录必要的资源引用、任务、付款结果与成本，不因供货身份自动授予进入客户桌面的权限。

当前没有供应商门户产品代码或真实对接。实际接口、指定账号开通能力及适用交付权限须核验；人工回报和正式接口都必须以真实结果验收。
