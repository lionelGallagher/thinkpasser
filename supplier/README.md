# 供应商端

自营及外部合作方使用同一供货门户。根目录运行 `npm run dev` 后打开 <http://127.0.0.1:5180/supplier/>，页面代码位于 `app/SupplierDesk.vue`。

演示支持切换电脑侧与卡／订阅侧供方，查看自己的资源、任务、准备时限、目标账号、结果回报和成本记录；可接单、填写结果并等待平台验收。电脑供方登记机器，卡／订阅供方登记脱敏引用、支持服务、报价、可供量和有效期，均需平台验收。未审核供方不开放新供货。

两类供方可以是不同机构，也可以同一家。指定账号开通是一类供货任务，不固定增加第三类供应商。卡自身的开卡、充值、冻结和销卡由供方管理；平台不采集页面展示的完整卡号或CVV。

卡经销商是给平台供卡的上游，客户侧不卖卡。纯供卡资源不声明 AI provider，也不向纯卡任务提供客户邮箱；具备已审核开通能力的合作方或平台自营承接指定账号任务。演示分别提供纯卡商和自营开通方身份，采购、实际扣款、AI 验收与结算仍为独立阶段。

当前全部资源和资金为本地演示，真实接单能力、资源引用、开通／认证流程和结算仍需对接。供货归属不自动授予客户桌面、文件或私人凭据访问权。
