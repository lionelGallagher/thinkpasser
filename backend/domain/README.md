# 电脑租期与 AI 加购规则

本模块实现已确认业务规则的纯计算部分，不调用支付服务、授予连接权限、清理数据或操作机器。

- 电脑有效期结束后进入三天文件导出保留期；三天结束后需要清理和重置，不能直接视为可重新分配库存。
- AI 加购按调用方提供的三十天标准价全额收费，有效期对齐电脑到期日，不按剩余天数折价。支持剩余一天或更短期限的购买，返回准确剩余毫秒数及到期时间供界面明示。
- 保留期内续费从原到期时间顺延。若保留期结束或已开始重置，不能承诺恢复原电脑环境。
- 电脑套餐周期由商品配置及其周期计算器提供，续期函数接收计算后的时长，不自行假定电脑租期也是三十天。

时间输入为服务端确定的 UTC Unix 毫秒整数，金额输入为最小货币单位的正安全整数。示例测试价格仅为测试数据，实际售价与币种由商品配置提供。

执行 `npm run test:product-domain` 验证规则。

主体服务接入时仍需完成身份认证、设备分配、订单验价、支付确认、状态锁定和幂等处理。此模块的时间状态不能单独作为连接或文件导出的授权依据。保留期清理任务必须重新核对续费与实际重置状态，纯计算结果不代表已经擦除或恢复机器。
