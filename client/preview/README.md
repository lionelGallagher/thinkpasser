# 桌面客户端界面预览

根目录运行 `npm run dev`，打开 <http://127.0.0.1:5180/client/preview/>。这是用网页呈现的Windows／Mac桌面客户端交互预览，不是可安装的原生包，也没有连接真实机器。

包含保存账号切换、当前账号独享电脑、连接资格、工作区、工具栏、文件示例、声音偏好和本地终端交互。终端仅响应help／pwd／ls／clear演示，不执行系统命令；未提供摄像头、麦克风、打印、隧道或任意设备ID入口。

真实客户端仍需按[原生集成](../rustdesk/README.md)和[远控详细设计](../../docs/design/03-remote-and-device.md)接入RustDesk核心、平台授权、设备连接密码、系统权限和打包签名。网页预览不代表这些工作完成；手机App不在范围内。

共享状态与组件在[web/shared/](../../web/shared/)，本目录保留桌面布局和交互；前端预览的数据适配与原生会话传输分别验收。
